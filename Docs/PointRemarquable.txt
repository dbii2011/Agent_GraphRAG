1.	Définition

Point Remarquable (PR) : Point géographique identifié par son code CI et son code CH. Le PR est essentiellement utilisé pour le calcul des horaires théoriques. Il est parfois utilisé pour délimiter des travaux ou un segment de tarification. 

Code Infrastructure (CI) : code à 6 chiffres propre à chaque site. 

Code Chantier (CH) : code alphanumérique à 2 caractères précisant un point particulier d’un lieu identifié par son libellé ou son code CI (par exemples BV pour Bâtiment Voyageur, AN pour Aiguille Nord, etc.).
