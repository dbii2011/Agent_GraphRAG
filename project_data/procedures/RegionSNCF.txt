1.	Définition 


•	Cet habillage indique les limites officielles des régions traversées pour les lignes classiques.
•	Pour les lignes LGV, la responsabilité à la région qui gère le suivi des circulations.
•	L’habillage région SNCF n’a pas de corrélation avec les compétences territoriales.  
2.	Caractéristiques générales

2.1.	Caractéristiques obligatoires


•	Il est défini par les informations suivantes :
o	Code ligne
o	Système de repérage ligne
o	PK début
o	PK fin
o	Région SNCF 
o	Dates de validité

3.	Règles générales pour la gestion 


Pour modifier les limites de régions SNCF :
	Borner les informations existantes.
	Créer les nouvelles limites en respectant les Pk et les dates.
