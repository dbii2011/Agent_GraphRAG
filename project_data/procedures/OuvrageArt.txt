1.	Définition

Un ouvrage d’art est une construction de génie civil, autre qu’un bâtiment, qui permet d’assurer et/ou protéger la continuité d’une voie de circulation. Il existe trois grands types d’ouvrages d’art ferroviaire : les ponts, les ouvrages de soutènements et les tunnels.
 
Dans le cadre de la description des OA dans GAIA, cinq types d’ouvrages sont décrits :
-	Les ponts rails
-	Les ponts routes
-	Les passerelles
-	Les tunnels ainsi que les galeries et tranchées couvertes
-	Les passages souterrains

Remarque : Les ouvrages en terre ne sont pas traités dans cette fiche procédure.

3.	Règles de nommage de l’objet 
3.1.	Libellé des obstacles

Les obstacles correspondent aux ouvrages franchis des routes, cours d’eau ou autres.
Le nommage de ces obstacles doit être renseigné lorsqu’ils sont connus, il devra respecter la construction suivante :
-	Voie communale : VC
-	Chemin Privé : CP
-	Chemin rural : CR
-	Route départementale : CD ou D suivi du n° de la route départementale.
-	Route Nationale : RN suivi du numéro de la route nationale.
-	Autoroute : A suivi du numéro d’autoroute.
-	Cours d’eau : indiquer le nom du cours d’eau.
-	Pour les autres obstacles il faut indiquer : indiquer Autre.
